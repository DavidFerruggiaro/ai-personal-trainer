# Bakeoff Results

This folder stores human-readable notes and summaries from PoseBakeoff runs.

Do not commit large video files or raw heavy exports unless intentionally curated. Local videos and generated artifacts should generally remain gitignored.

Use this folder for:

- smoke-test summaries
- overlay inspection notes
- engine comparison summaries
- final engine-selection write-up

Suggested file names:

```text
YYYY-MM-DD_smoke_test_apple_vision.md
YYYY-MM-DD_mediapipe_first_run.md
YYYY-MM-DD_engine_selection.md
```
