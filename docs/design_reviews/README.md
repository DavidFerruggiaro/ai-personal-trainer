# Design Reviews

This folder stores role-based review notes for substantial product or engineering changes.

Use the review lenses from `docs/agent_workflow.md`:

- Product co-founder review.
- Staff engineer review.
- QA review.
- Documentation/release review.

Suggested file names:

```text
YYYY-MM-DD_milestone_1_review.md
YYYY-MM-DD_post_set_review_ux.md
YYYY-MM-DD_pose_estimator_architecture.md
```
